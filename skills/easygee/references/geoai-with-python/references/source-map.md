# Source map and reuse boundaries

## Primary sources

- Book: <https://book.opengeoai.org/>
- Official repository and executable examples: <https://github.com/giswqs/GeoAI-Book>
- Source data examples: <https://source.coop/opengeos/geoai>
- GeoAI package: <https://opengeoai.org/>
- Leafmap: <https://leafmap.org/>
- Segment-geospatial: <https://samgeo.gishub.org/>
- Open Geospatial Solutions: <https://github.com/opengeos>

The generated skill is a synthesized method guide, not a mirror of the book. Chapter files point to the corresponding repository paths (`book/foundations`, `book/data`, `book/core_tasks`, `book/advanced`, and `book/qgis`).

## Code, text, and data

The book states that code examples are released under CC BY 4.0 and asks users to cite the book or repository. The written text, figures, and images are stated to remain copyrighted. This skill therefore favors concise paraphrase, small attributed code fragments, official links, and method extraction rather than reproducing prose or figures.

Suggested attribution:

> Wu, Q. (2026). *GeoAI with Python: A Practical Guide to Open-Source Geospatial AI*. Independently published. Available at <https://book.opengeoai.org/>.

## Version caveat

Package APIs, model checkpoints, Hugging Face access, QGIS plugin installation, cloud catalogs, and sample URLs are time-sensitive. Before running a copied command, check the current official documentation and record the versions that actually worked.
